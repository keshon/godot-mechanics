# Проверка проб

Запуск из корня проекта, PowerShell. `$env:GODOT` — путь к консольной сборке Godot 4.7.1.

```powershell
$env:GODOT = 'E:/Programs/godot/Godot_v4.7.1-stable_win64_console.exe'
& $env:GODOT --headless --path . --editor --quit
python tools/verify.py --all
python tools/verify.py --render
```

Первый вызов обновляет кэш классов. Второй выполняет проверки и запускает каждую пробу
и мультипробу на 120 кадров. Третий повторяет проверки с настоящим рендерером.
Для полного графического прохода: `python tools/verify.py --render --all`.
JSON с полным выводом сохраняется во временную папку; путь печатается в конце.
`--output путь.json` задаёт другое место. Ошибка Godot в журнале считается отказом,
даже если процесс вернул ноль. Предупреждения остаются в журнале для разбора.

`verify.gd` печатает сборку движка, CPU, GPU, рендерер и частоту физики. Проверяются:

- 26: касание заблокированного угла и пересечение стены; связность карт для зерён 0–99;
  одинаковая стоимость пути A* и поля потока; сегменты сглаженного пути.
- 16: восстановление прошлого и продолжения; отбрасывание чужого вида, неизвестной версии
  и обрезанного файла. Файлы проверки имеют префикс `audit_` и удаляются после прогона.
- 34: сто перемещений по миллиметру на 100 и 1000 км; совпадение начала координат рига
  и двух схем рельефа; сброс начала клавишей R.
- 31: два входа и выхода из сцены; число аудиошин возвращается к исходному.
- 49: летящий, дальний и доступный гвоздь; счётчики перехвата, срыва и сброса.
- М1/М2: движение с огнём в течение 90 физических кадров, прыжок/ручник, гильзы,
  трассеры, вызовы пробоин и искр по известной мишени, конечные координаты камеры; переключение видов М2.

Это проверки состояния и выполнения кода. Headless не проверяет картинку, шейдеры,
тембр звука и ощущение управления. В 24-й без рендерера показано отсутствие значений
шейдера, а не выдуманные значения по умолчанию. Startup не доказывает работу нажатий.

## Ручная приёмка, которая остаётся открытой

| проба | сценарий | что записать |
|---|---|---|
| М1 | стрельба стоя, в прыжке, на стене, в рывке и скольжении | читается ли попадание, мешает ли оружие движению, откуда идут эффекты |
| М2 | круг с газом, гребёнка, трамплин, занос с огнём; обе камеры | можно ли удерживать цель, виден ли результат ручки отставания |
| 49 | два человека проходят три пропасти, меняются ролями; раскачка 2/4/8 | решения обоих игроков, ожидание, понятность срыва, удобство устройств |

Ни один автоматический прогон не закрывает эти строки. В заметку переносится только
наблюдение состоявшейся игры, с указанием ролей и настроек.

## Повторный замер производительности

Старые таблицы без сборки или оборудования остаются историческими. Новому замеру нужны
ревизия кода, сборка, CPU/GPU, рендерер, разрешение, vsync, частота физики, зерно,
значения ручек, сценарий, прогрев, число повторов и способ агрегации. Сравнивать A–B–A
при одинаковой нагрузке. Проверки выше не переизмеряют исторические таблицы и не
восстанавливают неизвестные условия. Времена запуска и импорта не являются ценой механики.

Резкий headless-выход во время WAV-воспроизведения на Godot 4.7.1 даёт предупреждение
об AudioStreamPlaybackWAV (воспроизводится одним AudioStreamPlayer). Оно не скрывается
из журнала. Проверка обычного выхода из звуковой сцены даёт аудиосерверу завершить команды.

## Проба 50

Общий запуск `verify.py` также выполняет `verify_bike.gd`: 24 проверки подвески,
разгона, торможения, поворотов, прохождения трёх участков, воздушного управления
и сброса после падения. Отдельный запуск:

```powershell
godot --headless --path . --script res://tools/verify_bike.gd --fixed-fps 60
```

`--fixed-fps 60` фиксирует шаг сценария. Для галереи пробы 50 тот же флаг нужен
в запуске `res://tools/shot.tscn -- 50_bike`, чтобы кадр пришёлся на прыжок.
Таблица условий и результатов — в `probes/50_bike/README.md`.

Проверено 20 ноября 2026: 24 проверки пробы 50 прошли headless и Forward+/Vulkan,
1327 прежних проверок — headless. Startup остальных 48 проб и 3 мультипроб прошёл;
после смены формата звука отдельный headless-startup пробы 50 также завершился без ошибок.
Галерея пробы 50 снята в Vulkan. Ручная приёмка остаётся открытой.
