# 49 — двое за одним экраном: разные руки, разные глаголы

| | |
|---|---|
| эталон | It Takes Two |
| узлы | `Input.get_vector` на стик и клавиши сразу, `InputMap.action_set_deadzone`, `Input.joy_connection_changed`, `PhysicsRayQueryParameters3D`, `AnimatableBody3D` |
| размер | 4 скрипта, 442 строки |
| статус | открыта |

**Двое не ждут друг друга, пока глагол одного — условие глагола другого.** Мышь ставит
платформы, стик бегает и прыгает; платформы ставятся только в свете бегущего и оплачиваются
искрами, которые собирает он же. Ручки рвут эти связи по одной, и простой каждого игрока HUD
показывает в процентах. Пока в пробу не сыграли вдвоём, это гипотеза, а не вывод.

## Числа

Трасса проверена по тикам физики: бегущего ставят на платформу и дают ему прыгнуть.

| что | итог |
|---|---|
| вершина прыжка с земли | 1.59 м |
| платформа, 1.2 м | берётся прыжком |
| уступ, 2.4 м | только с платформы у его подножия |
| шаг с уступа на вершину, 1.8 м | только с платформы на уступе |
| вся трасса по двум платформам | проходится, финиш засчитан |

Ни уступ, ни вершина не берутся без чужого глагола: прыжок бегущего короче каждой из высот.

Ввод разводится по классу устройства, без номеров: всё, что двигает мышь, — строитель, всё, что
жмёт `run_*`, — бегущий. Синтетическими событиями:

| событие | бегущий |
|---|---|
| стик 0.15 при мёртвой зоне 0.20 | стоит |
| стик 0.15 при мёртвой зоне 0.05 | бежит на 0.105 |
| стик до упора | бежит на 1.0 |
| W на клавиатуре | бежит на 1.0 |
| кнопка A на геймпаде | прыгает |

**Отклонение за мёртвой зоной растягивается на весь ход, а не срезается.** 0.15 при зоне 0.05
даёт не 0.10, а 0.105 = (0.15 − 0.05) / (1 − 0.05). Уменьшая зону, получаешь не только
чувствительный центр, но и чуть другую скорость на любом отклонении.

## Переносить

**Двух людей различает класс устройства, если он разный.** Мышь против стика не требует ни
номеров, ни назначения игроков: действия бегущего просто не содержат событий мыши. Номер
устройства понадобится только второму геймпаду.

**Строитель получает причину отказа, а не молчание.** «Вне света бегущего», «нет заряда — нужны
искры», «на стену не встанет»: каждое из трёх показывает, какой связи сейчас не хватило, и
обращено к партнёру, а не к интерфейсу.

**Намерение бегущего — в мировых осях, поворот стика по камере делает риг.** Сущность не знает,
где камера; камера одна у рига, и «вверх на стике» значит «от камеры».
