**Вдвоём интересно, когда глаголы сходятся в одной секунде.** Метатель на клавиатуре и мыши
бросает гвозди в дерево, качающаяся на стике перелетает пропасть на них и опускает мост за
собой. Пока в пробу не сыграли вдвоём, это гипотеза, а не вывод.

## Числа

Период маятника, верёвка 3 м, размах 0.5 рад: 3.52 с против 3.47 по формуле для малых углов —
ровно поправка на большой угол, 3.47 · (1 + 0.5²/16). Гвоздь на 25 м/с летит 5.5 м за 0.22 с.
При перелёте на двух гвоздях второй нужен через 0.92 с после первого.

Перебор по пропастям в 14 м: места гвоздя, число раскачек, угол отпускания. Считаются только
посадки на дальнем берегу.

| предел размаха, раскачка | один гвоздь перелетел | два гвоздя перелетели |
|---|---|---|
| 45°, 2 м/с² | 0 из 220 | 8 из 60, вторая и третья пропасть — ни разу |
| 45°, 4 м/с² | **0 из 220** | **16 из 60, все три пропасти** |
| 45°, 8 м/с² | 13 из 220 | 28 из 60 |
| 50°, 4 м/с² | 5 из 220 | 20 из 60 |
| 55° и выше | переносит через каждую пропасть | — |

**Второй гвоздь делает нужным не ширина пропасти, а предел размаха.** Без предела каждый качок
добавляет к дуге, и одного гвоздя хватает на любую пропасть. Разбег при этом переходит в
качание целиком: хватаясь за гвоздь с бега, тело несёт скорость бега в дугу.

**Сильная раскачка (ручка 3) отменяет зависимость.** При 8 м/с² один гвоздь снова перелетает —
одна цифра в настройке стирает то, ради чего нужен второй игрок.
