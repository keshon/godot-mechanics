# 09 — эффекты без кода: реестр, таймлайн, пул

| | |
|---|---|
| эталон | — |
| узлы | `AnimationPlayer`, `GPUParticles3D`, `DirAccess`, `PackedScene` |
| размер | 2 скрипта, 276 строк |
| статус | закрыта, дата не записана |

**Эффект — это сцена. Реестр — это папка. Таймлайн — это `AnimationPlayer`.** Три вещи,
которые в движке уже есть, и вместе они заменяют редактор эффектов, которого в нём нет.

Отвечает на претензию к восьмой пробе, и претензия была верной: там слои сидели словарями
в коде, поэтому новый эффект означал правку скрипта — то есть привлечение того, кто пишет
код, а не того, кто смотрит на экран.

## Числа

| ручка | где живёт |
|---|---|
| количество, срок жизни, скорость, гравитация | `ParticleProcessMaterial`, инспектор |
| размер за время жизни | кривая, рисуется мышью |
| цвет за время жизни | градиент, собирается мышью |
| **когда что вступает** | `AnimationPlayer` внутри сцены эффекта |

Ни одной из них нет в коде — в этом весь смысл.

**Пул.** 127 запусков обслужены 32 узлами, 95 раз эффект пришёл из пула. После выхода на
режим новых узлов не создаётся вообще.

**Разворот по нормали**, четыре поверхности:

| куда стреляем | нормаль | +Y эффекта |
|---|---|---|
| пол | (0, 1, 0) | совпало |
| стена | (0, 0, 1) | совпало |
| панель, наклон назад 40° | (0, 0.643, 0.766) | совпало |
| панель, наклон вперёд 35° | (0, −0.574, 0.819) | совпало |

## Только руками

Обещание проверяется одним действием: скопировать сцену эффекта, поменять в ней цвета,
сохранить в `effects/`, нажать R. Без перезапуска, без кода, без сборки.

## Переносить

- **Верстак строится первым.** Никто его не даст, а без него эффект настраивается вслепую
  внутри игры.
- Соглашение вместо интерфейса: один узел `Anim`, одна анимация `play`. Не нужны ни базовый
  класс, ни скрипт на каждый эффект, ни таблица регистрации.
- Эффект стоит не в точке, а **на поверхности**: передавать вместе с позицией нормаль и
  разворачивать по ней. В самих сценах эффектов при этом не меняется ничего.
- Пул вместо удаления. Достаточно вынуть узел из дерева — он перестаёт и считаться, и
  рисоваться.

## Не переносить

- Настройки эффекта в коде. Ни в каком виде.
- Плоскостную арифметику для точки удара. Её хватало в шестой пробе на ровной земле; как
  только поверхности наклоняются, нормаль берётся только настоящим лучом — и геометрии
  нужны настоящие тела, меша для луча мало.
