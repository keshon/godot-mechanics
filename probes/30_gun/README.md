# 30 — стрельба: выстрел как аккорд

| | |
|---|---|
| эталон | FEAR, DOOM |
| узлы | вьюмодель в своём `SubViewport` и `World3D`, `Decal`, `GPUParticles3D`, пулы |
| размер | 2 скрипта, 691 строка |
| статус | закрыта 2 сентября 2026 |

**Оружие должно быть продолжением стрелка, и это не про эффекты.** Ствол смотрит туда же,
куда камера; отдача возвращает его на место сама; вспышка и трассер выходят из дульного
среза, а не из воздуха рядом. Пока хоть одно из трёх врёт, никакое количество искр не
спасает. Восемь слоёв на цифрах `1`…`8` — чтобы выключать по одному и слышать, чего не
хватает.

## Числа

| слои | кадр | вклад слоя |
|---|---|---|
| **все восемь** | **0.704 мс** | — |
| без искр | 0.607 | **0.097** |
| без дырок | 0.635 | **0.069** |
| без подвисания | 0.656 | 0.048 |
| без вспышки | 0.670 | 0.034 |
| без гильз | 0.680 | в шуме |
| без трассера | 0.682 | в шуме |
| **ничего, только луч** | **0.570** | весь аккорд **0.134** |
| повтор «все восемь» | 0.673 | шум **±0.031** |

Выше шума поднимаются только искры и дырки. Главный вывод не в порядке слоёв, а в порядке
величин: весь аккорд стоит примерно седьмую часть миллисекунды. Ощущение выстрела — задача
о замысле, а не о бюджете; спорить надо о таймингах, а не о цене.

Тайминги, которые и есть ощущение:

| | |
|---|---|
| вспышка | 45 мс, и меряется ВРЕМЕНЕМ: один кадр невидим при высокой частоте и навязчив при низкой |
| гильза | через 40 мс после выстрела. С нулевой задержкой она внутри вспышки и читается как её часть |
| подвисание | 35 мс на 6 % скорости, по РЕАЛЬНЫМ часам: `delta` и есть искажаемая величина |
| отдача | пружина оседает за пятую долю секунды |

## Только руками

Когда ось ствола, отдача и точка выхода сходятся, собирается аккорд: работает не сумма
слоёв, а то, что они попали в такт друг другу. До этого момента каждый слой по отдельности
выглядит верным, а выстрела нет.

Заметнее всех оказались искры, гильзы и вспышка с трассерами — ровно те три, где пришлось
лезть глубже всего. Совпадение неслучайное: как настоящие читаются именно те слои, в
которые вложено физическое поведение, а не картинка.

Доворот ствола на 9° и крен на 3° — чтобы читались сразу верх и бок — при игре
отвергаются мгновенно: оно смотрит не туда. Форму надо набирать ступенькой силуэта
(ресивер толще, цевьё уже), а ось оставить параллельной взгляду.

## Переносить

- **Вьюмодель отдельной камерой в своём `World3D`.** Узкий FOV на оружие поверх широкого
  на мир — единственный честный рычаг «массы» ствола. Плюс приватный свет: оружие читается
  одинаково в тёмном подвале и на солнце. Общий мир не годится — свет, ограниченный
  `light_cull_mask`, всё равно протекал на стену.
- **Ось оружия = ось взгляда.** Никаких доворотов ради силуэта.
- **Слой на клавише.** Не отладочная роскошь, а единственный способ услышать, что держит
  выстрел.
- **Поведение вместо картинки.** Направление искр — из угла удара и отражения; длина
  росчерка — из скорости; растяжение следа — из косинуса падения; задержка гильзы — из
  механики затвора. Каждый раз, когда параметр выведен из физики, эффект читается лучше и
  настраивается легче.
- **Пул как замысел.** Кольцо на 64 следа это правило «стена держит 64 дырки», а не
  оптимизация. Так устроен любой шутер, и игрок это узнаёт.
- **Гонять пробу вчетверо быстрее задуманного.** Три ошибки нашлись только там: подвисание
  копилось и залипало на 0.06 навсегда (событие, а не состояние — события не складываются);
  отдача убегала за верх экрана без потолка на смещение и скорость; разброса не было
  вовсе, и сорок восемь дырок штабелировались в одну.

## Не переносить

- **Подвисание на автоматическом огне.** Стрельба превращается в череду микрозамираний.
  Только под тяжёлое оружие и добивание, где выстрелы редкие.
- **Трассер на каждой пуле.** Красиво ровно один магазин. В настоящей ленте трассер каждый
  третий-пятый именно потому, что иначе он перестаёт быть отметкой и становится шумом.
- **Трассер как подсвеченную траекторию.** Это ЛЕТЯЩАЯ пуля: короткий отрезок, три кадра
  на комнату. Весь путь разом читается как веер ярких прутьев с вершиной в лице игрока. И
  начинать его надо в двух метрах от среза, иначе параллакс дульного среза виден при
  каждом повороте головы.
- **Тряску синусами.** Двух синусов хватило, чтобы убить дрожь белого шума, но это
  заплатка: нужна кривая с затуханием и разной формой под разные события.
- **Ручную геометрию оружия из коробок.** Для пробы правильный ход, в игре — первое, что
  заменяется моделью.
- **`SHADING_MODE_UNSHADED` вместе с emission.** В unshaded на экран идёт ровно albedo:
  `emission_energy 16` не делал ничего. Свечение задаётся HDR-цветом самого albedo. Ошибки
  нет, предупреждения нет, просто пыльная полоска вместо пули.
- **`Basis.scaled()` для вытягивания вдоль направления.** Она умножает СТРОКИ, то есть
  масштабирует по осям родителя: трассер растягивался вдоль мирового Z, а не вдоль полёта.
  Видно только тогда, когда что-то не выровнено по оси.
