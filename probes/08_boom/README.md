# 08 — взрыв, разобранный на слои

| | |
|---|---|
| эталон | — |
| узлы | `GPUParticles3D`, `ParticleProcessMaterial`, `CurveTexture`, `GradientTexture1D`, `OmniLight3D`, шейдер преломления |
| размер | 2 скрипта, 443 строки |
| статус | закрыта, дата не записана |

**Взрыв — стопка эффектов на разных часах.** Решают кривые, а не текстуры: белый круг с
правильными кривыми читается взрывом, фотографический атлас с неправильными — нет.

## Числа

| ручка | что решает |
|---|---|
| сроки жизни слоёв | расхождение между ними **и есть** эффект |
| палитра за время жизни | где горячее, где остывает, где исчезает |
| кривая размера | резкое расширение и медленное оседание |
| количество | фотореализм — сотни мелких, стилизация — единицы крупных |
| гравитация слоя | всё поднимается, искры падают; контраст и продаёт физику |
| `Engine.time_scale` | не эффект, а инструмент: без него слои не разглядеть |

Полная скорость, все слои включены:

| время | что ещё живо |
|---|---|
| 0.12 с | вспышка кончилась |
| 0.19–0.43 | кольцо, огонь, искры, дым |
| 0.51 | кольцо ушло |
| 0.56 | огонь ушёл |
| 1.1 | искры и дым |
| 3.2 | узел удалил себя сам |

## Переносить

- Слой — это четыре числа: срок жизни, кривая размера, палитра, гравитация. Больше в нём
  ничего нет.
- Свет в стопку. Одна строка, и это единственный слой, который трогает мир вокруг.
- Замедление времени как инструмент разработки, с камерой, идущей мимо него.

## Не переносить

- Сборку слоёв словарями в GDScript. Добавить эффект = править скрипт, и его не добавит тот,
  кто смотрит на экран. Это чинит девятая проба.
- `Engine.time_scale` как игровой рычаг: он глобальный и переживает сцену.
- Переключатель PHOTO/STYLISED. Это вилка для сравнения двух подходов, а не настройка —
  в игре стиль один и выбран заранее.
