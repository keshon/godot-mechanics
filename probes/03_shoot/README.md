# 03 — стрельба: сцена как заготовка

| | |
|---|---|
| эталон | Quake 3 |
| узлы | `PackedScene`, `Area3D`, `Timer`, `RigidBody3D`, `Marker3D` |
| размер | 3 скрипта, 334 строки |
| статус | закрыта 21 августа 2026 |

**Заготовка отвечает, ЧТО это такое; оружие — какое оно сегодня.** Числа живут на том, что
не умирает: вкладка Remote бесполезна для узла, живущего три секунды.

## Числа

| ручка | что решает |
|---|---|
| `fire_interval` | не темп стрельбы, а сколько объектов живёт одновременно |
| `bullet_speed` + `use_sweep_detection` | вместе решают, попадает ли пуля вообще |
| `bullet_punch` | 1 — толкнуть ящик, 30 — разметать штабель |
| `inherit_shooter_velocity` | 0 — очередь при стрейфе изгибается (Quake), 1 — стоит ровно перед тобой |

Свежий штабель, десять выстрелов:

| | попаданий | в пике живых |
|---|---|---|
| 25 м/с, развёртка вкл. | 5 | 8 |
| 150 м/с, развёртка вкл. | 7 | 2 |
| 150 м/с, развёртка **выкл.** | **0** | 3 |

Ноль — не округление. За один тик физики пуля проходит 2.5 м, а ящик шириной 0.9 м целиком
помещается между двумя замерами.

Сходимость ствола с перекрестьем: промах был постоянные 18 см (смещение ствола от глаза),
стал 0.000 м.

## Только руками

Первая проба, где в мире появляется то, чего при загрузке не было, и потом исчезает само.
Счётчик ALIVE это показывает: объекты рождаются пачкой и растворяются по одному.

Настройки при этом оказались размазаны — половина ручек на игроке, половина в файле пули, и
единого места, где лежит поведение выстрела, не было вовсе.

## Переносить

- Порядок штамповки: сделать → записать внутрь всё, что нужно знать → положить **в мир**, а
  не под того, кто создал. Три шага, одинаковые для пули, врага и взрыва.
- Соединение сигнала прямо в сцене: таймер жизни пули связан со встроенным `queue_free`.
  Объект умирает от старости, и за это не отвечает ни строки кода.
- Сходимость ствола и перекрестья. Камера спрашивает мир, во что смотрит, пуля летит из
  ствола в эту точку.

## Не переносить

- Обнаружение попаданий только через перекрытие `Area3D` — для всего, что движется быстрее
  собственного размера. Только развёртка отрезка.
- CSG-коллизию там, где по геометрии будут стрелять.
