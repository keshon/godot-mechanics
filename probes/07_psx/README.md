# 07 — стиль как набор ограничений

| | |
|---|---|
| эталон | PlayStation |
| узлы | `SubViewportContainer`, `ShaderMaterial`, вершинный шейдер, `hint_screen_texture`, `Image.set_pixel` |
| размер | 3 скрипта, 555 строк |
| статус | закрыта 2 сентября 2026 |

**Стиль — это набор ограничений, а не набор ассетов.** Связный вид получается из правил, и
для одиночки без художественных навыков это единственный доступный способ.

## Числа

| ручка | что делает |
|---|---|
| `shrink` | делитель разрешения. Самое дешёвое и самое заметное из всего |
| `snap_coarseness` | сетка, на которую падают вершины, в отрисованных пикселях |
| `levels` | ступеней цвета на канал. 32 ≈ настоящие 15 бит, 4 — плакат |
| `dither` | меняет полосатость на мелкий шум, который глаз читает как цвет |
| `floor_subdivide` | размер треугольника, то есть **сила аффинного искажения** |
| `scan_period` | пикселей окна на одну отрисованную строку. Равен `shrink`, а не двум |
| `crt` | виньетка, изгиб, растекание цвета. Единственная ручка «телевизора» |
| `fog_density` | прячет короткую дальность прорисовки, и это тоже часть стиля |

**Строки развёртки, соседние строки экрана при `shrink = 4`:**

| | строка N | строка N+1 |
|---|---|---|
| период считался в пикселях окна | 0.3581 | 0.3581 |
| период считается от `shrink` | 0.2936 | 0.3581 |

Ноль разницы в первой строке — это узор, попадавший каждой экранной строкой в одну фазу.

## Только руками

**Первый заход дал набор приёмов, а не эпоху,** и разбор того, почему именно, оказался
ценнее самих приёмов. Три причины, все видны только глазом:

- аффинность была перебрана — не потому, что эффект сильный, а потому что пол был нарезан
  на 13×13;
- строки развёртки почти не читались;
- шахматка на всех поверхностях не опознаётся как графика той эпохи.

Собралось только после кирпича, досок, бетона, гранёных бочек и прохода телевизора.

**Изгиб кинескопа в шесть сотых** — величина смешная, а разница между «окном» и
«телевизором» вся в ней.

## Переносить

- Ограничение как выразительное средство: сначала правило, потом ассет.
- Всё, что меряется в пикселях, обязано знать, **в чьих именно** пикселях. Огрубление цвета
  — свойство кадрового буфера, считается внутри вьюпорта; строки развёртки — свойство
  экрана, живут снаружи, поверх уже увеличенной картинки.
- Вид эпохи — это не только артефакты, но и **реакция художников на артефакты**. Плотные
  полы и нарезанные стены были ответом на отсутствие перспективной коррекции.

## Не переносить

- **Точность эмуляции.** Настоящая консоль имела фиксированную точку в вершинном конвейере,
  отсутствие Z-буфера с сортировкой по полигонам и порядок отрисовки, ломавшийся на
  пересечениях. Цель — узнаваемость, а не совместимость; гнаться за буквальностью значит
  воспроизводить и баги, за которые эпоху не любили.
- Строки развёртки как обязательный элемент. Отдельный проход снаружи, к консоли отношения
  не имеет, и без него образ держится.
- Шахматку как испытательную поверхность для стиля. Она честна для проверки одного приёма
  и не складывается в сцену: ограничение без предмета читается поломкой.
