# 53 — анимация персонажа: переходы и прерывания

| | |
|---|---|
| эталон | персонаж кооперативного платформера |
| узлы | `CharacterBody3D`, `AnimationPlayer`, `Skeleton3D`, `Skin`, импортированный GLB |
| размер | 2 скрипта, 251 строк |
| статус | открыта |

**Гипотеза: переходы читаются, не задерживая управление.** Один персонаж сравнивает
ходьбу и бег, поворот на месте, отрыв, подъём, падение, посадку и прерываемое взаимодействие.
Полосы пола помогают увидеть скольжение стоп, подиумы — сход с края, стенка — остановку
движения при удерживаемом вводе.

## Управление

WASD / левый стик — движение относительно камеры; мышь / правый стик — камера.
SHIFT / B — ходьба, ПРОБЕЛ / A — прыжок, F / X — взаимодействие.
Q/E / LB/RB — поворот на месте. R / Y — сброс. ESC освобождает курсор, клик захватывает.

1 сравнивает смешивание 0 / 0.12 / 0.30 с. 2 включает изменение темпа клипа по фактической
скорости, 3 сравнивает быстрый и медленный разворот модели. Скорость подбирается относительно
настроечных значений 2.5 м/с для Walk и 6 м/с для Sprint. Это параметры пробы,
а не паспортные скорости автора ассета.
Движение, поворот или прыжок прерывают действие. Посадка не блокирует следующее движение.

## Что проверено

`tools/verify_motion.gd` проверяет наличие Skin и 53 костей, позу руки во время действия, прерывание движением и прыжком,
возврат руки после перехода, шаг и бег, темп клипа при частичном вводе и изменённом
ограничении скорости, поворот без перемещения, отрыв → подъём → падение → посадку → покой,
самостоятельное окончание действия, падение без прыжка и сброс истории визуала.

## Пайплайн импортированной модели

В `assets/AnimationLibrary_Godot_Standard.glb` лежит исходный ассет Quaternius из
`worldbox-1/shared/assets/`. Лицензия CC0 сохранена в `assets/LICENSE.txt`.
Копируется исходный GLB, а не производный файл из `.godot/imported`: Godot сам
создаёт кэш импорта в этом проекте. У модели 53 кости, скиннинг и 45 исходных клипов.

`model.tscn` инстанцирует GLB и разворачивает его под направление контроллера.
Импорт добавляет RESET из позы покоя; AnimationPlayer использует deterministic blending,
чтобы неполные треки при прерывании возвращались к базовой позе.
Словарь `clips` в `player.gd` связывает состояния контроллера с именами импортированных
анимаций: Idle, Walk, Sprint, Jump_Start, Jump, Jump_Land, Interact.
Поворот пока использует Walk, подъём и падение — общий Jump: отдельных подходящих
клипов для этих состояний здесь нет. Отрыв и посадка укладываются в окна 0.16 и 0.25 с,
чтобы длинное ожидание в исходных клипах не задерживало управление.

Обновление ассета: заменить GLB с сохранением структуры скелета и имён клипов,
повторить импорт и проверки. При других именах меняется словарь `clips`.
Правки самих клипов выполняются в исходном ассете. Эта проба проверяет модель и
анимации одного скелета; перенос анимаций на другой скелет и IK стоп ещё не реализованы.

Движение определяет контроллер, а клипы меняют только позу. Корневая анимация не двигает
коллизию. Положение модели интерполируется между физическими тиками, камера следует
отрисованной позиции. Эти проверки не доказывают качество анимации или отсутствие
скольжения стоп на всех скоростях.

## Только руками

Пройти от шага к бегу, резко развернуться, упереться в стену, начать действие и прервать его
прыжком. Сойти с подиума без прыжка и сразу побежать после посадки. Сравнить три времени
смешивания и фиксированный/согласованный темп. Записать, когда движение выглядит
тяжёлым, когда ноги скользят и какие переходы мешают читать действие.
