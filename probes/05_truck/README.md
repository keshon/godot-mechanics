# 05 — шестиколёсник: подвеска и раскладка привода

| | |
|---|---|
| эталон | SnowRunner |
| узлы | `VehicleBody3D`, `VehicleWheel3D` |
| размер | 3 скрипта, 433 строки |
| статус | закрыта, дата не записана |

**Раскладка привода не значит ничего, пока шина держит.** Значит стабилизатор
поперечной устойчивости, которого в Godot нет и который дописывается за двадцать строк.

## Числа

**Сколько весит колесо.** Тот же грузовик, те же 2400 кг, в покое:

| | сжатие каждой пружины |
|---|---|
| 6×6 | 0.09 |
| 4×4, средняя ось поднята | 0.14 |

Шесть рессор против четырёх: каждая просела на 56% больше. Прямой ответ на «как количество
колёс влияет на физику», читается в табло.

**Куда приложена тяга.** 14000 Н суммарно, ускорение за первые полсекунды:

| раскладка | на колесо | ускорение |
|---|---|---|
| все шесть | 6 × 2333 Н | 5.46 м/с² |
| передняя | 2 × 7000 Н | 5.46 м/с² |
| средняя | 2 × 7000 Н | 5.46 м/с² |
| задняя | 2 × 7000 Н | 5.46 м/с² |
| передняя + задняя | 4 × 3500 Н | 5.46 м/с² |

Одинаково до последней цифры. `engine_force` — настоящая сила, она просто складывается.

**Стабилизатор.** Резкий поворот влево, ~10 м/с, все три бара одинаковые:

| жёсткость | крен |
|---|---|
| 0 | 1.44° |
| 2000 | 1.28° |
| 5000 | 1.10° |
| 10000 | 0.91° |
| 20000 | 0.74° |

Крен вдвое меньше, монотонно, за двадцать строк кода.

## Только руками

**Раскладка привода за рулём не различима** — все пять вариантов ведут себя одинаково, и
замер это подтверждает. Разница появляется только за порогом срыва.

**У стабилизатора край виден только в игре.** В таблице ряд монотонный до самого верха, а
на 40000 грузовик начинает бороться сам с собой и теряет половину скорости, на 80000
встаёт. Число продолжает расти после того, как поведение кончилось — ползунок пришлось
обрезать там, где кончается физика, а не там, где кончаются цифры.

## Переносить

- `position.y` колеса как готовый датчик хода подвески. Отдельного геттера нет и не нужно:
  подвеска двигает сам узел, а меш ездит ребёнком бесплатно.
- Стабилизатор за двадцать строк: разница сжатия двух пружин оси, толчок вверх на просевшей
  стороне и вниз на другой. Без него машина валится в повороте.
- Крутить сцепление, а не раскладку привода.

## Не переносить

- Ожидание, что у колеса есть подвеска в автомобильном смысле. `VehicleWheel3D` — луч и
  пружина: ни развала, ни кастера, ни схождения, ни длин рычагов, ни центра крена.
- Жёсткие бары на бездорожье. Сила прикладывается только там, где колесо касается земли, а
  достаточно жёсткий бар сам поднимает внутреннее колесо в повороте — толкаться становится
  не от чего.
