# 55 — две камеры: теснота, высота и раздельные пути

| | |
|---|---|
| эталон | кооперативный платформер |
| узлы | два `SubViewport`, `Camera3D`, `CharacterBody3D`, объёмы камеры |
| размер | 4 скрипта, 401 строка |
| статус | открыта |

**Гипотеза: каждый вид сохраняет посадку и ориентиры.** Два игрока в одном физическом
мире проходят узкий коридор, уступы и расходящиеся дорожки. Камеры независимы;
зоны задают направление, наклон и дистанцию каждой из них. Это отдельная проба камеры,
а не интеграционная сборка анимации, сессии и движущихся платформ.

## Управление

P1: WASD, мышь, ПРОБЕЛ — прыжок, SHIFT — рывок.
P2: стрелки, IJKL — камера, ENTER — прыжок, CTRL — рывок.
Удержание прыжка меняет высоту; второе нажатие даёт второй прыжок.
Геймпад: левый/правый стики, A — прыжок, X — рывок.

Один подключённый пульт получает P2, два — оба игрока. Нажатие 0 заново назначает
пульты по списку подключённых; автоматической смены слота при отключении нет.
Клавиатура управляет только слотом без пульта. Полный жизненный цикл устройств — предмет 51.
R сбрасывает текущий участок, TAB выбирает следующий. ESC освобождает мышь, клик захватывает.

1 сравнивает защиту камеры от стен, 2 — авторские зоны и свободную орбиту,
3 — скорость перехода 3 / 15 с⁻¹ (исходно 5). Ручки меняют обе камеры для сравнения.
Выход из зоны возвращает сохранённую ручную орбиту; вращение мышью/стиком внутри зоны
меняет эту сохранённую орбиту, сама зона временно задаёт направление вида.

## Числа и устройство

Физика 60 Гц. Скорость персонажа 7 м/с, воздушное ускорение 16 м/с²,
прыжок 9 м/с, рывок 17 м/с на 0.18 с. Поддержка движения скопирована в пробу;
зависимостей от соседних проб нет. Видимые позиции интерполируются между физическими
тиками; обе камеры следуют тем же позициям на каждом кадре отрисовки.
Направление движения берётся из текущего направления соответствующей камеры,
включая переход между зонами.

Свободная дистанция 6.5 м; коридор задаёт 3.3 м, высота — 8 м, ветки — 7 м.
Сфера радиусом 0.28 м проверяет путь камеры от цели; при препятствии дистанция
сокращается сразу, после выхода увеличивается плавно. Ближняя плоскость — 0.05 м.
В контрольной точке коридора при боковом взгляде длина плеча около 1.76 м;
сфера радиусом 0.25 м вокруг камеры не пересекает стену.

`tools/verify_coop.gd` проверяет общий мир двух viewport, независимость зон и орбит,
видимость персонажей и следующей вертикальной посадки, защиту от стены и её отключение,
выход из незавершённого перехода, сброс, двойной прыжок и рывок. Отдельная проверка
сравнивает цель камеры с отрисованной позицией персонажа при движении.
Численные проверки не измеряют комфорт или читаемость препятствий для человека.

## Только руками

Пройти коридор у стены, повернуть камеру к стене, прыгнуть под перемычкой.
Пройти уступы, затем одновременно двигаться по разным веткам. Выйти из зоны в середине
перехода и сбросить участок во время прыжка. Проверить посадки на своей половине экрана,
в том числе при 144 Гц. Записать потерянные ориентиры и места, где камера скрывает цель.

Защита не решает случай, когда сама точка наблюдения уже помещена внутрь стены,
прозрачность заслоняющих объектов и постановку камеры для произвольного уровня.
