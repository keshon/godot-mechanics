# 57 — совместный возврат: один упал, оба упали

| | |
|---|---|
| эталон | кооперативный платформер |
| узлы | `CharacterBody3D`, две камеры, `Marker3D` безопасных точек |
| размер | 2 скрипта, 365 строк |
| статус | открыта |

**Гипотеза: ошибка одного не останавливает другого.** Два игрока пересекают пропасти.
Один может продолжать, пока другой возвращается. Первый добравшийся до зелёной полосы
закрепляет общую точку; повтор больше не отправляет партнёра на предыдущий остров.

## Управление

P1: WASD, ПРОБЕЛ — прыжок и второй прыжок, SHIFT — рывок, F — падение.
P2: стрелки, ENTER — прыжок и второй прыжок, CTRL — рывок, DELETE — падение.
Пульт: левый стик, A — прыжок, X — рывок, Y — падение. Удержание прыжка меняет высоту.
Один пульт получает P2, два — обоих игроков; 0 переназначает подключённые пульты.

R повторяет от общей точки, N начинает с нуля, 3 роняет обоих, P ставит паузу.
1 сравнивает задержку личного возврата 1.2 / 2.5 с, 2 — общего 1.8 / 3.0 с.
Камеры следуют за каждым персонажем; во время ожидания показывают безопасную точку.

## Числа и наблюдения

| случай | правило |
|---|---|
| упал один | через 1.2 с возвращается к последней общей точке; второй продолжает |
| упали оба | личные таймеры отменяются, через 1.8 с возвращаются оба |
| второй упал перед окончанием личного таймера | начинается общий повтор, раннего личного возврата нет |
| выживший закрепил новую точку во время ожидания | ожидающий вернётся уже туда |
| новая точка и окончание таймера в одном тике | сначала фиксируется точка, затем происходит возврат |
| пауза | таймеры и движение заморожены |
| один дошёл до финиша | закрепляется финальная точка; сообщение об общем успехе ждёт обоих |

Точка принимается только стоя на земле в пределах зелёной зоны. Возврат на ранний
остров не уменьшает прогресс. Падение ниже −3 м запускает ту же процедуру, что F / DELETE.
Места появления разнесены на 2.4 м. Видимые позиции интерполируются между физическими
тиками; камеры используют те же позиции.

При 60 Гц физики автоматический маршрут проходит обе пропасти со вторым прыжком,
без рывка. Это проверка достижимости, а не удобства. `tools/verify_recovery.gd` также
проверяет продолжение движения выжившего, гонки таймеров, паузу, повтор, запрет
активации точки в полёте и возврат отставшего к уже открытому финишу.

## Только руками

Пройти вдвоём, по очереди падать перед полосой и после неё. Одному оставаться на
старте, пока другой закрепляет остров. Упасть почти одновременно и поставить паузу
во время ожидания. Сравнить задержки: понятно ли, где появится партнёр, не мешает ли
его возврат продолжению игры и не теряется ли ощущение общего прогресса.

Проба не сохраняет прогресс на диск, не восстанавливает головоломку и не реализует
оживление партнёром. Отказы устройств исследуются отдельно в 51 и 56.
